==================================================
ABOUT THE INTEGRATION
==================================================

KirtnixTracker is my own landing-page and Telegram tracking software.

Landing pages are imported into KirtnixTracker and served through the platform.

KirtnixTracker has a canonical JavaScript integration:

https://tracker.kirtnix.in/api/public/kx.js?lp=YOUR_LP_UUID

The landing page contains Telegram CTA elements.

KirtnixTracker's kx.js identifies the primary Telegram CTA element using:

data-kx-cta="1"

When the page loads, KirtnixTracker handles the Telegram CTA destination dynamically.

Therefore the landing page must NOT contain a hardcoded Telegram invite URL.

The landing page itself must NOT generate Telegram invites.

The landing page itself must NOT call the Telegram Bot API.

The landing page only needs to expose the CTA elements correctly so KirtnixTracker can handle them.

==================================================
STEP 1 — FIND THE PRIMARY TELEGRAM CTA
==================================================

Scan the document to find the main Hero CTA (e.g., "Talk on Telegram" / "Join Telegram").

Only ONE primary CTA element should be designated as the tracked Telegram conversion trigger using:

data-kx-cta="1"

Other secondary buttons/navigation (such as navbar "Get in Touch" or footer contact links) must NOT create duplicate independent tracking invitations; they should scroll to the primary CTA or act as normal navigation.

==================================================
STEP 2 — REMOVE HARDCODED TELEGRAM INVITE URLs
==================================================

For the primary CTA:
- Set href="#" initially (kx.js will inject the visitor-specific invite).
- Add data-kx-fallback="https://t.me/YOUR_CHANNEL" with your channel's public handle/fallback.

Do NOT hardcode a static invite link into href.

==================================================
STEP 3 — ADD THE KIRTNIX CTA HOOK
==================================================

The primary CTA must contain:

data-kx-cta="1"
data-kx-fallback="https://t.me/YOUR_CHANNEL"
href="#"

Example:

<a
  class="btn-primary"
  href="#"
  data-kx-cta="1"
  data-kx-fallback="https://t.me/YOUR_CHANNEL"
  rel="noopener noreferrer"

  <span class="btn-icon">➤</span>
  Talk on Telegram
</a>

Add this exact script once, immediately before the closing </body> tag:
